# Handson5 Output

## Startup
- Project: `week_3/ASPNETCore8_WebAPI/Handson5`
- Swagger available at `http://localhost:<port>/swagger`

## JWT Authentication
- `GET /api/auth/token?userId=1` returns a JWT token with role `Admin`
- The token is valid for 2 minutes
- Requests without a valid Bearer token return `401 Unauthorized`

## Roles and authorization
- `EmployeeController` is protected with `[Authorize(Roles = "POC,Admin")]`
- The token generated by `AuthController` uses role `Admin`
- If `POC` is removed from roles, `Admin` still passes
- Modifying the token invalidates authentication and returns `401`

## CORS
- CORS is enabled globally with `AllowAnyOrigin`, `AllowAnyHeader`, and `AllowAnyMethod`
- This allows local applications and Postman to access the API
