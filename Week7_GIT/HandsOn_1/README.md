# HandsOn_1 - Git Basics

This folder contains a simple Git hands-on project for learning basic Git commands.

## Objectives

- Familiar with Git commands such as `git init`, `git status`, `git add`, `git commit`, `git push`, and `git pull`.

## Lab overview

In this hands-on lab, you will learn how to:

- Set up your machine with Git configuration
- Integrate Notepad++ as the default editor in Git Bash
- Add a file to a source code repository

## Prerequisites

- Install Git Bash on your machine

## Suggested steps

1. Configure Git user name and email.
2. Set Notepad++ as the default Git editor.
3. Create a new repository folder.
4. Add a file such as `welcome.txt`.
5. Track and commit the file.
6. Push it to a remote repository.

## Starter file

A sample file named `welcome.txt` is already included in this folder.
