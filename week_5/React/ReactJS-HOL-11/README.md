ReactJS HOL 11 — Event Handling Lab

This hands-on lab demonstrates React event handling patterns implemented in `src/App.jsx`:

- Increment / Decrement counter buttons
- `Say Welcome` button showing argument handling in event handlers
- `Press Me` button that demonstrates a synthetic `onPress`-style handler
- `CurrencyConvertor` component converting Indian Rupees to Euros

Run:

- `npm install`
- `npm run dev`

Open `http://localhost:4171` (or the port printed by Vite) to view the lab. The screenshot is saved to `Output.png`.
