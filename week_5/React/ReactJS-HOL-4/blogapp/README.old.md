# BlogApp (Lifecycle Hooks Hands-on)

This project demonstrates class component lifecycle hooks: `componentDidMount` and `componentDidCatch`.

Run locally:

```bash
cd week_5/React/ReactJS-HOL-4/blogapp
npm install
npm start
```

The `Posts` component fetches posts from `https://jsonplaceholder.typicode.com/posts` and renders the first 10.
