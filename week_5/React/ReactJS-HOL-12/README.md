# ReactJS-HOL-12 — Conditional Rendering

## Objectives

- Explain conditional rendering in React
- Define element variables
- Explain how to prevent components from rendering

## What You Will Learn

- Implement conditional rendering in React applications

## Prerequisites

- Node.js
- NPM
- Visual Studio Code

## Estimated Time

60 minutes

## Project: ticketbookingapp

A React application where:

- **Guest users** can browse flight details (read-only table).
- **Logged-in users** can book tickets from the flight list.
- A **Login** button switches to the User page; a **Logout** button returns to the Guest page.

## Run

```bash
cd week_5/React/ReactJS-HOL-12
npm install
npm run dev
```

Open the URL shown in the terminal (e.g. http://localhost:5173).
