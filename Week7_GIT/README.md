# Week 7 - Git Hands-On Labs

This folder contains a collection of Git practice projects for the Week 7 training exercises.

## Included hands-on projects

- HandsOn_1 - Git basics and repository setup
- HandsOn_2 - Using `.gitignore` to ignore unwanted files
- HandsOn_3 - Branching and merging
- HandsOn_4 - Resolving merge conflicts
- HandsOn_5 - Cleanup and pushing changes to a remote repository

## What each folder contains

Each hands-on folder includes:

- A README with the lab objectives and steps
- Sample files or starter content for practice
- A simple structure that can be used directly in Git Bash

## How to use this folder

1. Open the relevant hands-on folder.
2. Read the README carefully.
3. Follow the listed Git commands in Git Bash.
4. Use the sample files provided to practice the workflow.

## Suggested learning flow

1. Start with HandsOn_1 to learn repository setup and basic Git commands.
2. Continue with HandsOn_2 to understand ignored files.
3. Practice branching and merging in HandsOn_3.
4. Resolve conflicts in HandsOn_4.
5. Finish with HandsOn_5 to learn cleanup and remote synchronization.
